# txt-chat — редактор txt + чат + база людей

Мини-приложение: редактируешь `.txt` файлы в браузере, одним кликом отправляешь их содержимое в общий чат, и у сервера есть база всех зарегистрированных пользователей.

**Ноль зависимостей.** Только Node.js — сервер, пароли (scrypt), база (JSON-файл) и живая доставка (SSE) — всё встроенное. Клиент — один HTML-файл, без сборщиков.

## Запуск

Нужен только [Node.js](https://nodejs.org) (любая версия ≥ 18):

```bash
node server.mjs
```

Открой **http://localhost:4322** — зарегистрируйся и всё работает.

Порт меняется переменной `PORT`:

```bash
PORT=8080 node server.mjs   # Windows PowerShell: $env:PORT=8080; node server.mjs
```

## Что внутри

| Раздел | Возможности |
|---|---|
| ✏️ Редактор | создание, правка, переименование, удаление, автосохранение (1.5 с), Ctrl+S, скачивание `.txt` |
| 💬 Чат | общий чат, живая доставка (SSE), отправка txt-файла в чат одним кликом |
| 👥 Люди | база зарегистрированных: имя, email, дата регистрации |
| 🔐 Аккаунты | регистрация и вход, пароли — scrypt + соль, сессии по токену |

## Где данные

Всё в папке `data/` рядом с сервером:

- `data/db.json` — пользователи, сессии, сообщения, txt-файлы.

## Как это работает

```
txtchat/
  server.mjs        сервер: HTTP API + статика + SSE, ноль зависимостей
  public/index.html клиент: одна страница, вкладки Редактор / Чат / Люди
  data/db.json      база: создаётся автоматически при первом запуске
```

- Пароли хранятся как scrypt-хеш с индивидуальной солью — в открытом виде их в базе нет.
- Сообщения доставляются подключённым клиентам мгновенно через Server-Sent Events.
- txt-файлы приватны: каждый видит только свои.

## Хостинг

Работает на любом Node.js-хостинге (Railway, Render, Fly.io, VPS). Порт берётся из `process.env.PORT`, адрес `0.0.0.0` — как принято на платформах. На локалке, для друзей — запусти на своём компьютере, они зайдут по `http://<твой-IP>:4322` из той же сети.
